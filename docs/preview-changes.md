# 이번에 바뀐 것 (실전 롤플레이)

> **한눈에** 보내 주신 «실전 롤플레이»(실시간 음성으로 AI 대표와 TA·AP·PC·클로징 연습)를 허브 서버에 붙여 미리보기에 올렸습니다. 노트북 크롬·엣지에서 이어폰을 끼고 왼쪽 메뉴 «실전 롤플레이»(또는 «메뉴 › 연습하기»)를 누르면 미팅 자리 화면이 뜨고, 사진·영상 속 대표님과 목소리로 바로 대화합니다. 기존 «AP 롤플레이»(글자)는 그대로 둡니다.

| 도구 | 무엇이 들어 있나 |
|---|---|
| [실전 롤플레이 (음성)](tools/rp-live.html) | 보내 주신 연습 화면 그대로: 단계(TA·AP·PC·클로징), 관계·난이도·성향, 대표 정보, 연습 시간 10~60분(시간 되면 자동 종료), 엔진 OpenAI(기본)·Gemini. 나이대·성별 맞춤 장면·영상·목소리, 끝나면 다시 듣기·말하기 지표·단계별 채점 |
| [실전 롤플레이 기록 보기](tools/rp-live-admin.html) | 모든 연습의 녹음·대화록·피드백을 듣고 내려받기 |

## 단장님 제안 «더할 것»을 넣은 것

| 제안 | 어떻게 |
|---|---|
| 연습하기에 새 도구로 | 메뉴 «연습하기» 안에 «실전 롤플레이 (음성)»·«실전 롤플레이 기록 (지점장)». 기존 AP 롤플레이(글자)는 그대로 |
| 연습자 이름 꼭 넣기 | 이름(또는 호칭)이 없으면 시작하지 않음 |
| 소속 지점 칸 | 연습 화면에 «소속 지점», 기록 보기에 지점 칸과 «소속 지점으로 찾기» |
| 1인당 하루 횟수 제한 | 한 사람 하루 5번 (팀 전체 하루 60번과 함께, 둘 다 바꿀 수 있음) |
| 반론 목록을 누구나 보태기 | 대표 반응 설계 문서를 «함께 만들기»에 연결, 검수 자격사 목록 추가 |
| 부부(두 목소리) | 단장님 원본처럼 다음 단계로 꺼 둠 |

## 허브에 붙이면서 바꾼 것

| 무엇을 | 어떻게 |
|---|---|
| 시험 서버(노트북 파이썬) | 허브 서버(Apps Script)에 같은 일을 하는 기능을 새로 넣음: OpenAI 임시 열쇠, Gemini 1회용 토큰, 단계별 채점(Claude Sonnet), 녹음 저장, 기록 목록. 실제 허브가 쓰는 서버 주소는 그대로 두고, 미리보기는 따로 연 주소를 씀 |
| API 열쇠 3개 | 서버의 «스크립트 속성»에만 넣음. 사이트·저장소·브라우저에는 없음. 브라우저는 10분짜리 임시 열쇠만 받음 |
| 연습 기록 | 시트 «실전롤플레이» 탭에 대화·점수·피드백, 녹음(webm)은 허브 담당 구글 드라이브의 비공개 폴더 |
| 관리자 코드(관리자.json) | 지점장 비밀번호(보험 MBTI 기록 보기와 같은 번호)로 들어감 |
| 입구 | 허브 입구 비밀번호를 다시 넣음. 팀 비밀번호가 있어야 서버가 임시 열쇠를 줌 |
| 하루 횟수 | 하루 새 연습 60회까지 (비용 관리, 숫자는 바꿀 수 있음) |
| 대표 반응 설계 문서 | «이 파일을 고치면 바로 반영» 문장을 «보완 남기기로 알려 주시면 반영»으로 (허브 문서는 서버가 바로 읽지 않아서) |
| 열기 | 허브 안 작은 창이 아니라 화면 전체로 열림 (마이크 허락을 받기 위해) |
| 시작 버튼 | 원본은 브라우저 음성 인식이 없으면 버튼을 막았는데, 실시간 대화형은 필요 없어서 마이크만 되면 시작되게 (휴대폰·다른 브라우저 대비). 카톡 안 브라우저면 «다른 브라우저로 열기» 안내 |
